# EN
## Training and Inference

This folder includes two notebooks: one for training a GPT2 model and the other for inference with retrieval mechanism.

* `inference_GPT2.ipynb`: Includes basic data manipulators for inference and GenerateWithRetrieval class for generating with retrieval procedures. 

* `training_GPT2.ipynb`: Training the GPT2 model with [huggingface-transformers](https://github.com/huggingface/transformers) as backend.
